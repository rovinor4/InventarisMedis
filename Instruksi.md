# REST API untuk sistem inventaris medis rumah sakit
Buatkan backend REST API untuk sistem inventaris medis rumah sakit.

Gunakan bahasa pemrograman php dan database mysql untuk username_db dan password_db nantinya aku masukkan sendiri. jangan lupa buat migration.sql nanti aku masukan manual

Fitur minimal:
1. Menyimpan data alat medis.
2. Menampilkan daftar alat medis.
3. Mengubah data alat medis.
4. Menghapus data alat medis.
5. Mencatat stok alat medis.
6. Mencatat peminjaman dan pengembalian alat.

Buat agar aplikasinya bisa langsung dijalankan.
